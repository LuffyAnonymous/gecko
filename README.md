# Gecko — Digital Menu

A single-page, mobile-first digital menu for Gecko, the beach café/kiosk at Kite Beach, Umm Suqeim, Dubai — plain HTML/CSS/JS with no backend, no database, and no build step, meant to be reached by scanning a QR code. To deploy, drag this folder into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) (or any static host) and point the menu's QR code at the resulting URL; to update menu items, prices, or colors later, edit `index.html` and `css/style.css` directly — no rebuild required.
